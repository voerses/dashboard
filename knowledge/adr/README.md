# Architecture Decision Records (ADRs)

Durable architectural decisions for the crypto backtest engine. Each ADR captures a single decision with context, alternatives considered, and consequences. Future sessions (human or AI) must cite the relevant ADR before re-opening a decision. Reversals require a superseding ADR.
